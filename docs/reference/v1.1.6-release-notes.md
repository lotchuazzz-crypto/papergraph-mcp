# v1.1.6 Bugfix Notes

Status: development candidate; not yet tagged or published.

This release fixes four confirmed defects without changing workspace schema 9
or the supported import sources.

- Re-importing the same LaTeX or PDF paper no longer deletes reading sessions,
  user notes, checkpoints, reading queues, or manual reference resolutions.
  Generated evidence is rebuilt atomically. Saved checkpoints other than
  explicitly skipped ones become blocked for review, queue-item evidence carries
  `reimport_review_required`, sessions
  receive a warning note, and manual resolutions carry the same review flag.
  Re-confirming an unchanged resolution clears its flag. Old search snapshots
  are removed because their source evidence may no longer be current.
- DOI resolver URLs with uppercase schemes/hosts now normalize to the same
  identity as their lowercase forms.
- One non-serializable provider record now causes a partial provider outcome
  while valid sibling records remain available.
- Non-string provider-list elements now produce a clear validation error
  instead of an internal `TypeError`.

Back up a workspace before upgrading or re-importing important papers. This
version does not migrate the database schema, but references in retained
reading work must be reviewed after a source refresh. A saved target that no
longer exists is detached from its session or queue rather than fabricated.

The package version is 1.1.6 for development testing. Until a v1.1.6 tag is
published, public installation instructions continue to pin released v1.1.5.
