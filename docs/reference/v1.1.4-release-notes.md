# v1.1.4 Release Notes (preparation)

- Bounded, resumable citation expansion with approved automatic identity
  selection, manual review, cumulative limits, pause/cancel, durable decisions,
  cross-process execution lease and interrupted-import reconciliation.
- Nine matching Workspace, CLI and MCP entry points; JSON/Markdown reference
  trees and additive Reading Report/Evidence Triage summaries.
- Reusable MIT three-paper fixtures, synthetic provider responses, golden
  outputs, offline runner and real MCP stdio regression tests.
- Transactional schema 7 → 8 migration and preserved search history on refresh.

Defaults: depth 2, 10 new papers, 100 searches, 500 edges. Only arXiv sources and
explicit local PDFs are importable. Ambiguous/conflicting candidates are not
automatically imported. No unlimited crawling, paywall bypass, theorem matching
or proof verification. An advance time budget is checked between steps, not a
hard network timeout.

Back up workspaces before migration. Older versions cannot open schema 8.
Actual Codex, Claude and AutoClaw clients are `documented_not_run`; the offline
CLI and MCP protocol tests are separate verified baselines. See the
[compatibility matrix](client-compatibility.md) and
[walkthrough](../walkthroughs/bounded-reference-expansion.md).

This development branch prepares the release; it does not publish a tag or
GitHub Release. Pinned v1.1.4 install recipes become usable after publication.
