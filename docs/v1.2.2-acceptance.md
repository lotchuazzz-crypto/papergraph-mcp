## Fourth candidate: raw reading and proof ownership are separate

Independent third-round reports demonstrated both unknown/wrapped titles and
QED inside raw blocks after which unrelated discussion acquired false edges.
No finite title list or later terminal marker establishes ownership. Default
automatic extraction therefore keeps only the explicit proof heading's first
physical line, with no automatic continuation across later lines or blocks.
This intentionally removes automatic late-proof edges. Reading stays complete
through raw locators; candidate context must not be promoted to proof evidence.

Clip at the first explicit terminal position; an ambiguous quotation/word mention
of QED stops the excerpt without searching for a later QED. Multiple proof
headings cannot extend the earlier excerpt. Persist exact block-relative ranges
as derived fragment evidence without changing the original raw block or schema.
Fragments locate their complete raw containers but never duplicate raw pagination.
Keep short explicit first-line references, unresolved internal evidence, offsets,
restart stability and no-write reads as positive controls. Keep all prior title
counterexamples and test arbitrary unknown titles, wrapped punctuation, same-block
after-QED discussion and later-QED traps with no dependency/order promotion.

Legacy stored extraction remains unchanged and unverified. Explicit reimport is
needed to adopt the new policy; never overwrite reading state to pass acceptance.
Freeze the new method/coverage semantics, README/setup/client/Chinese instructions
and actual installed smoke together in R before rebuilding new canonical bytes.
