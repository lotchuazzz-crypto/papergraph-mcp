## Genuine local Git-free public-index acceptance

A fresh rootless bubblewrap filesystem used the existing Python 3.12.15 runtime,
real uv and uvx executables, required shared libraries, certificates, a new
writable temporary directory and the read-only checking script. It did not mount
the host root, installed Git or a source checkout. The minimal root contained no
Git package or executable; the original check verified execution, ordinary
absolute Git paths and the package database. Git was not hidden by altering the
host PATH. This isolation shares the WSL kernel and network; it is not an OCI
image or a GitHub Actions run.

`5595fb3ab1a49b9dd62d7cccc338386ff91c0264bad091e98f4b67fe39f2a133`

Earlier rootfs attempts lacked a C++ library or incorrectly substituted a uv

executables and unmodified checker; no failed run is counted as a pass.

## Reproduction and evidence boundaries

Use `scripts/check_release_artifacts.py` on freshly downloaded official files,
then the installed package with `scripts/accept_latex_structure.py` and
`scripts/accept_latex_counter_context.py`, each with a new absolute `--output`
outside the checkout. For example, `uv run --no-project --no-config --no-env-file
--default-index https://pypi.org/simple --with papergraph-mcp==1.2.3 python
scripts/accept_latex_counter_context.py --output OUTPUT` runs all 11 synthetic
cases. Replace `OUTPUT`; do not reuse a database or output directory. The Git-free
checker must run in an actually Git-free Linux filesystem, never a host with Git
removed from PATH.

This acceptance used synthetic inputs only. It did not rerun full development
tests, private-paper acceptance, actual client configuration/restart, macOS or
other Python/platform combinations. Prior CI and research evidence keep their
own scope. It does not establish proof correctness or complete dependency
coverage; see the [LaTeX contract](latex-extraction.md) and
[release notes](v1.2.3-release-notes.md).

Current guidance and onboarding now select 1.2.3. R, `v1.2.3` and published files
remain unchanged; their build-time prepared-state documentation is a historical
snapshot. Setup must still verify a Git tag live against the reviewed R before
Git-source launch. Historical [1.2.2 evidence](v1.2.2-publication.md) remains
unchanged and is not used to establish this release. Existing client settings,
workspaces and reading data are not automatically changed or re-extracted.
