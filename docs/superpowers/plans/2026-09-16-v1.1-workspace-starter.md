# v1.1 Workspace Starter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Workspace Starter / Reading Project Bootstrap workflow that plans or creates a local reading project from explicit paper inputs and emits `START_HERE.md` plus `papergraph-starter-manifest.json`.

**Architecture:** Add `src/papergraph/starter.py` for normalization, validation, orchestration, artifact rendering, and manifest rendering. Add thin `Workspace` methods, MCP tools, CLI commands, docs, and tests around that module.

**Tech Stack:** Python 3.10+, SQLite-backed `Workspace`, existing Paper Map / Reading Report / Cross-Paper Reading Plan builders, pytest, argparse CLI, MCP tool wrappers.

## Global Constraints

- Do not use subagents.
- Use TDD: write failing tests before production code.
- No new extraction logic.
- No database schema migration.
- Explicit paper inputs only.
- Bootstrap always writes both `START_HERE.md` and `papergraph-starter-manifest.json`.
- Generated artifacts must not include timestamps or random IDs.
- Ambiguous arXiv requests and unsafe artifact overwrites stop before writes.
