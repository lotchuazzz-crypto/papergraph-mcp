# v1.1.2 Reference Import Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v1.1.2 user-confirmed reference resolution loop from external blocker to persisted target and optional import.

**Architecture:** Add a small reference-resolution layer beside the existing External Import Planner. The planner continues to produce extraction-backed blockers; the new layer stores user-confirmed target metadata, imports arXiv/PDF targets through existing workspace import paths, and lets reports summarize resolved blockers without rewriting extracted evidence.

**Tech Stack:** Python 3.10+, SQLite workspace schema, existing PaperGraph workspace APIs, MCP stdio tools, argparse CLI, pytest.

## Global Constraints

- No subagents; execute inline in this session.
- Follow TDD: write failing tests first, verify failure, implement minimal code, verify pass.
- Do not add online search in v1.1.2.
- Do not auto-download publisher PDFs, DOI URLs, or arbitrary web URLs.
- Do not modify existing extracted citation/evidence rows to pretend the original paper contained user-supplied metadata.
- Persist user-confirmed DOI/URL/metadata targets even when they are not importable.
- Import only `arxiv` and local `pdf` targets.
- Keep output deterministic: stable IDs, sorted lists, sorted JSON keys.
