## Implementation observations

Focused tests: 32 passed. Real old checkout reports the v1.1.4 feature branch,
dirty files, and HEAD different from origin/main; no checkout mutation performed.
Actual CLI doctor and stdio initialize/get_environment_diagnostics verified the
new capability fields. The package and published source pin intentionally remain
1.1.7 while the v1.2.0 work is unreleased.

The first full run exposed a test isolation issue: a nonrepository fixture nested
under the checkout discovered its parent Git repository. Added a Git discovery
ceiling to that fixture; focused tests also pass with an in-checkout basetemp.

Later batches remain open: DOI source discovery/import and dependency reading UX.
Final first-batch full suite: 688 passed, 1 skipped in 101.39s. `git diff --check`
passed. No fresh-agent behavioral validation is claimed; user-driven first-use
tests remain the next source of onboarding feedback. No push or release performed.
Potential reading-order issue found during inspection: reversing DFS preorder can
violate prerequisite ordering for shared dependencies. Reproduce before fixing.
