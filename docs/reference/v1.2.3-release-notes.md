# v1.2.3 — bounded LaTeX structure and citation repairs

PyPI 1.2.3 is published. Actual public-byte, fresh-index Windows/Linux and local
genuinely Git-free acceptance passed on 2026-10-18; see the
[publication record](v1.2.3-publication.md). Current consumer guidance pins 1.2.3.
The dedicated GitHub public-index CI has not run and the GitHub Release is not
published. Equal version strings alone do not establish publication.

## Highlights

- Recognize theorem aliases declared with shared or section counters, including
  optional result titles, whitespace and unnumbered declarations.
- Prefer complete explicit proof goals over adjacency. Unknown, conflicting or
  compound goals remain unowned. Unsupported counter mutations and display
  definitions leave numeric ownership and references unknown.
- Distinguish mathematical brackets and command options from citations while
  preserving explicit cite commands, including within mathematics. Retain
  source-backed inline bibliography entries and their original offsets.

See [the extraction contract](latex-extraction.md) for supported forms, aliases,
counter uncertainty and synthetic CLI/stdio acceptance entry points.

## Compatibility

No new runtime dependency, MCP schema change or automatic database migration.
Existing workspaces and reading state are preserved. Improved extraction applies
to new imports; use a new database to review results before explicitly choosing
to reimport existing papers. Existing data is not silently re-extracted.

The parser is a bounded lexer, not a TeX interpreter or proof checker. Section
outlines remain unimplemented; formula references may remain unknown. Extracted
reading order is source-backed evidence, not complete mathematical prerequisites.
External references are not automatically downloaded. PDF's conservative proof
ownership and historical stored evidence retain their existing contracts.

## Verification and publication gates

The LaTeX repair passed synthetic regressions, local independent acceptance and
Linux/Windows Python 3.10/3.12 CI before this version preparation. Version-specific
source, wheel/sdist and installed CLI/stdio checks passed for the frozen clean
source, canonical Linux distribution hashes and embedded manifests. The protected
publisher succeeded, followed by actual public-index acceptance. The immutable
source/tag and published artifacts must never be replaced in place.

Publication requires same-run immutable artifacts, strict source/metadata/hash
checks and the human review for environment `pypi`. After upload, verify actual
official JSON/simple entries, download both files and compare hashes, then run
fresh-cache official-index CLI/stdio acceptance. Workflow success alone is not
proof of public installation. No private research input is part of the release.
