## Actual Git-free consumers

Wheel and sdist each ran in a separate fresh minimal bubblewrap filesystem
containing the existing Python runtime, shared libraries and ordinary utilities.
The host has Git; its executable directories, package database, home and source
checkout were not mounted into either consumer. Git was absent from the consumer
filesystem, not hidden by modifying the host PATH. Executable and package absence
checks passed before bootstrap and after each consumer test.

Each consumer installed uv 0.13.1 into a fresh temporary virtual environment,
used a separate empty uvx cache and installed its local archive with dependencies
from the official public index. The sdist built successfully without Git.
Both passed version/doctor, real stdio initialize/tools/diagnostics, generated PDF
import and dependency reading, and the fixed R/manifest validation. No consumer
downloaded Git or a paper. An initial harness run omitted `realpath` and `dirname`,
which uv's launch script needs; adding those existing utilities fixed the harness.

subsequent official Python 3.12 checks below. Windows remains a development test
